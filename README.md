# RideStack

Lawrenceville, GA mobility launch dashboard — rideshare, delivery gigs, medical courier, NEMT (Verida), and government contracts.

Modeled after [SellStack](https://github.com/ugcrocky-dev/sellstack), localized for Gwinnett County.

## What's inside

- **20+ platforms** across rideshare, delivery, medical courier, NEMT, government portals, and ops tools
- **Income path picker** (rideshare, delivery, medical courier, NEMT, gov contractor)
- **Filterable directory** with apply steps on every card
- **Thorough apply guides** for medical courier, government contracts, and Verida NEMT
- **Persisted launch checklist** (saved in your browser)
- **Budget-based starter stacks** for week-one execution

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

Insurance limits, broker assignments, and portal UIs change. Always verify current requirements on official sites (Uber/Lyft, Verida, SAM.gov, Georgia DOAS, Gwinnett Purchasing) before spending money or submitting bids. This is a planning map, not legal or insurance advice.
